# Telegram Service Shop Bot

Modular aiogram 3 + SQLite Persian service shop. Includes users, products, stock, manual payments, orders, wallet, discounts, reseller/referral, tickets, tutorials, gifts/gift cards, favorites, notifications, broadcasts, admins/permissions, Feature Manager, audit, analytics, Excel import/export, backups and maintenance foundation.

Excluded by design: shopping cart and multi-language.

Setup: copy `.env.example` to `.env`, set a BotFather token, put the owner numeric Telegram ID in `ADMIN_IDS` and `SUPER_ADMIN_IDS`, then `pip install -r requirements.txt` and `python main.py`. Never commit `.env`; rotate any exposed token before publishing.
